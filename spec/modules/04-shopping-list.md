# Module: Shopping List

## หน้าที่
ให้ user จดรายการของที่อยากซื้อไว้ล่วงหน้าก่อนไปร้าน 7-Eleven เป็น checklist ธรรมดา **ไม่มีราคา** (เหตุผลดูใน spec หลัก หัวข้อ "ฟีเจอร์ที่พิจารณาแล้วตัดออก") และส่งลิสต์ไป LINE ได้

## เก็บข้อมูลด้วย localStorage — ไม่มี backend/DB
ลิสต์ของ user ถูกเก็บไว้ใน browser ของเครื่องนั้นๆ ผ่าน `localStorage` เท่านั้น (key เช่น `7elevenfinder.shoppingList`) — **ไม่ sync ข้ามอุปกรณ์** ถ้า user เปิดแอปจากมือถือกับคอมคนละเครื่อง ลิสต์จะไม่เหมือนกัน เพราะไม่มี account/server เก็บกลาง นี่คือ trade-off ที่ยอมรับได้ตาม scope "ไม่มี backend" ของโปรเจกต์

## Flow การทำงาน (ทีละขั้น)

1. **โหลดลิสต์เดิม** — ตอนเปิดหน้า อ่านค่าจาก `localStorage` ถ้ามี ถ้าไม่มี (ครั้งแรก) แสดง empty state
2. **เพิ่มรายการ** — พิมพ์ชื่อของในช่อง input → เลือกหมวดหมู่ (เครื่องดื่ม/ขนม/อาหารพร้อมทาน/ของใช้ประจำวัน) → กด "เพิ่ม" → item ใหม่ถูก push เข้า array และเขียนกลับ `localStorage` ทันที
3. **ปรับจำนวน** — ปุ่ม +/- ข้างแต่ละ item เปลี่ยนค่า quantity แล้วเขียนกลับ `localStorage` ทันที (ทุกการเปลี่ยนแปลง sync ลง storage แบบ real-time ไม่ต้องกด "บันทึก" แยก)
4. **ติ๊กว่าหยิบแล้ว** — checkbox หน้า item, เปลี่ยน state `checked: true/false` — item ที่ติ๊กแล้วแสดงแบบ dim/ขีดฆ่า แต่ยังอยู่ในลิสต์ (ไม่ลบทิ้ง)
5. **ลบรายการ** — ปุ่มลบ (ไอคอนถังขยะ) ต่อ item เดียว ลบทันทีไม่ต้อง confirm (เพราะ undo ง่าย แค่พิมพ์ใหม่)
6. **ล้างทั้งลิสต์** — ปุ่ม "ล้างลิสต์" ที่มุมบน **ควรมี confirm dialog** ก่อนลบจริง (ต่างจากลบทีละรายการ เพราะกระทบข้อมูลทั้งหมดและกู้คืนไม่ได้)

## จัดกลุ่มตามหมวดหมู่
รายการแสดงแบ่งเป็น section ตามหมวดหมู่ (เครื่องดื่ม/ขนม/อาหารพร้อมทาน/ของใช้ประจำวัน) แทนที่จะเป็น list เดียวยาวๆ — ช่วยให้ดูง่ายเวลามีของหลายอย่าง

## ฟีเจอร์ "ส่งไป LINE"

### กลไกการทำงาน
1. ผู้ใช้กดปุ่ม **"ส่งไป LINE"**
2. ระบบ serialize ลิสต์ปัจจุบัน (เฉพาะ item ที่ยังไม่ติ๊กหยิบแล้ว หรือทั้งหมดแล้วแต่ดีไซน์) เป็นข้อความ plain text เช่น:
   ```
   🛒 ลิสต์ของที่จะซื้อที่ 7-Eleven
   เครื่องดื่ม: น้ำเปล่า x2, กาแฟกระป๋อง x1
   ขนม: มันฝรั่งทอด x1
   ```
3. Encode ข้อความด้วย `encodeURIComponent()` แล้วต่อเป็น URL: `https://line.me/R/share?text={encoded text}`
4. เปิด URL นี้ (เช่น `window.location.href` หรือ `<a href>`) → ระบบปฏิบัติการเปิดแอป LINE ขึ้นมาเอง พร้อมข้อความอยู่ในกล่องแชร์ ให้ user เลือกเองว่าจะส่งหาใคร/กลุ่มไหน

### ข้อจำกัดสำคัญ
- **ใช้ได้เฉพาะมือถือที่ลง LINE app ไว้แล้ว** — `line.me/R/share` เป็น URL scheme ที่ออกแบบมาสำหรับเปิดแอป LINE บนมือถือ ไม่ทำงานบน LINE for PC/Mac
- ถ้าเปิดจากคอมพิวเตอร์หรือเครื่องที่ไม่มี LINE ติดตั้ง: ควรมี fallback — เช่น ปุ่ม "คัดลอกข้อความ" ให้ user เอาไปวางเองที่ไหนก็ได้ หรือใช้ Web Share API (`navigator.share`) เป็นทางเลือกเสริมถ้า browser รองรับ
- ไม่ต้องมี LINE Developer account, API key, หรือ backend ใดๆ — เป็นแค่ URL scheme ธรรมดา จึงเข้ากับสถาปัตยกรรม "ไม่มี backend" ของโปรเจกต์ได้พอดี

## Shortcut: "ดูร้านใกล้ฉันพร้อมไปซื้อ"
ปุ่มลัดจากหน้า Shopping List พาไปหน้า Map/List Store ทันที (ขอ GPS ถ้ายังไม่มีพิกัด) — เชื่อมสองโมดูลเข้าด้วยกัน: จดลิสต์เสร็จ → กดปุ่มนี้ → เจอร้านใกล้สุดพร้อมนำทางต่อได้เลย

## หมายเหตุทางเทคนิค
- localStorage มีขนาดจำกัด (~5-10MB แล้วแต่ browser) แต่ shopping list เป็น text ล้วนขนาดเล็กมาก ไม่มีทางเต็มในการใช้งานจริง ไม่ต้องกังวลเรื่อง quota
- ควร wrap การอ่าน/เขียน `localStorage` ด้วย try/catch เผื่อกรณี browser ปิด storage (private mode บางตัว) — ถ้า error ให้ fallback เป็น in-memory state ชั่วคราวพร้อมแจ้ง user ว่าลิสต์จะหายถ้าปิดแท็บ
- ข้อความที่ส่งไป LINE ควรมี hard limit ความยาว (ตัด URL scheme มีข้อจำกัดความยาว query string ในบาง mobile browser) — ถ้าลิสต์ยาวมากอาจต้องสรุปย่อหรือเตือน user
