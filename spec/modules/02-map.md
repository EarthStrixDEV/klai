# Module: Map

## หน้าที่
แสดงร้าน (จากแบรนด์ที่เลือกไว้) รอบตัว user บนแผนที่แบบ real-time ดึงข้อมูลสดจาก OSM ทุกครั้ง ไม่มีการเก็บ cache ถาวร — รองรับ **เลือกได้หลายแบรนด์พร้อมกัน** (multi-select) ตั้งแต่ v0.5 เป็นต้นไป

## Brand Registry — ที่มาของรายชื่อแบรนด์
หน้านี้ไม่ hardcode ว่าค้นหาเฉพาะ 7-Eleven อีกต่อไป แต่อ่านรายชื่อแบรนด์ที่รองรับ (ชื่อ, ประเภท, OSM tag, สี pin) จาก **Brand Registry** ไฟล์ config เดียวที่ใช้ร่วมกับหน้า List Store และ Gas Station Combo Finder (ดูรายละเอียดเต็มในสเปคหลัก หัวข้อ 4) ค่าเริ่มต้นเมื่อเปิดหน้า Map ครั้งแรกติ๊ก 7-Eleven ไว้ให้อัตโนมัติ

## Flow การทำงาน (ทีละขั้น)

1. **ขอตำแหน่ง** — เรียก `navigator.geolocation.getCurrentPosition()` (ถ้ายังไม่มีพิกัดส่งมาจากหน้า Home) ได้ `{lat, lng}` ของ user
2. **อ่านชุดแบรนด์ที่ติ๊กไว้** จาก brand filter chips (ดูหัวข้อ Interaction) — อย่างน้อย 1 แบรนด์เสมอ (ปิดครบทุกอันไม่ได้ ต้องเหลืออย่างน้อย 1)
3. **ยิง Overpass query แบบรวม (union)** ตามรัศมีที่เลือก (default 1 กม.) และ tag ของทุกแบรนด์ที่ติ๊กไว้ในคำสั่งเดียว:
   ```
   [out:json][timeout:15];
   (
     node["shop"="convenience"]["brand"~"7-Eleven",i](around:{radius_m},{lat},{lng});
     node["amenity"="cafe"]["brand"~"Inthanin",i](around:{radius_m},{lat},{lng});
   );
   out body;
   ```
   *(ตัวอย่างนี้คือกรณีติ๊ก 7-Eleven + อินทนิล พร้อมกัน — ยิ่งติ๊กหลายแบรนด์ ยิ่งมีบรรทัด `node[...]` เพิ่มใน query เดียวกัน)*
4. **รับผลลัพธ์** — array ของ node แต่ละอันมี `id`, `lat`, `lon`, `tags.name` (ถ้ามี), `tags.brand` — ใช้ `tags.brand` จับคู่กลับไปยัง Brand Registry เพื่อรู้ว่า node นี้ควรใช้สี pin อะไร
5. **คำนวณระยะทาง** จาก user ไปแต่ละร้านด้วย Haversine formula (client-side, ไม่ใช้ DB)
6. **Render แผนที่** — Leaflet + OSM tile, วาง pin ทุกร้าน **สีต่างกันตามแบรนด์** (ตาม Brand Registry) พร้อม legend มุมหนึ่งของแผนที่บอกว่าสีไหนคือแบรนด์ไหน ไฮไลต์ร้านที่ใกล้ที่สุดโดยรวม (ไม่แยกแบรนด์) ด้วย ring เน้น
7. **แสดง bottom sheet** ของร้านที่ใกล้สุด (หรือร้านที่ user แตะ pin) — ชื่อร้าน, แบรนด์ (พร้อมสี badge), ที่อยู่ (จาก tag `addr:*` ถ้ามี), ระยะทาง

## Interaction

| การกระทำ | ผลลัพธ์ |
|---|---|
| ติ๊ก/ถอดติ๊ก brand chip (multi-select) | ยิง Overpass query ใหม่ทันทีด้วยชุดแบรนด์ปัจจุบัน — ไม่ต้องขอ GPS ซ้ำ ป้องกันไม่ให้ถอดติ๊กจนเหลือ 0 แบรนด์ |
| เปลี่ยน radius chip | ยิง Overpass query ใหม่ด้วยรัศมีใหม่ (คงชุดแบรนด์เดิม) ไม่ต้องขอ GPS ซ้ำ |
| พิมพ์ในช่องค้นหา | filter ฝั่ง client จากผลลัพธ์ที่ดึงมาแล้ว (match ชื่อร้าน/ที่อยู่ ข้ามทุกแบรนด์ที่แสดงอยู่) — **ไม่ยิง API ใหม่** |
| แตะ pin บนแผนที่ | เปลี่ยนร้านที่แสดงใน bottom sheet |
| แตะ legend ของแบรนด์ใดแบรนด์หนึ่ง | shortcut ถอดติ๊ก/ติ๊กแบรนด์นั้นอย่างเดียว (เท่ากับกด chip เดียวกัน) |
| กด "นำทาง" | เปิด deep link `https://www.google.com/maps/dir/?api=1&destination={lat},{lng}` แท็บใหม่ — เปิด Google Maps app ถ้าเครื่องลงไว้ ไม่มีก็เปิดเว็บ Google Maps แทน (โฟกัสแค่ Google Maps เจ้าเดียว ไม่แยก Apple Maps ให้ iOS) |
| กด GPS button (มุมขวาบน) | ขอตำแหน่งปัจจุบันซ้ำ แล้ว re-center แผนที่ + ยิง query ใหม่ (คงชุดแบรนด์เดิม) |

## Error / Loading state
- ระหว่างรอ Overpass ตอบ: แสดง loading spinner ทับแผนที่ (ยิ่งติ๊กหลายแบรนด์ query ยิ่งใหญ่ขึ้น เวลารออาจนานขึ้นเล็กน้อย)
- ถ้า fetch fail หรือ timeout: แสดงข้อความ "ไม่สามารถโหลดข้อมูลร้านได้ ลองใหม่อีกครั้ง" พร้อมปุ่ม retry
- ถ้าไม่พบร้านในรัศมีที่เลือก: แนะนำให้ user ขยายรัศมี **หรือ** เพิ่มแบรนด์ที่ค้นหา (ถ้าติ๊กไว้แค่แบรนด์เดียวที่สาขาน้อย เช่น Chao Doi)
- ถ้า pin เยอะมากจนแผนที่รก (ติ๊กหลายแบรนด์ + รัศมีกว้าง): พิจารณาทำ marker clustering — ยังไม่ตัดสินใจ ดู Open Questions ในสเปคหลัก

## หมายเหตุทางเทคนิค
- Overpass เป็น public server ฟรี ไม่มี SLA — ควรมี fallback ไป mirror server อื่นเผื่อ server หลักช้า/ล่ม (ดูรายละเอียดใน spec หลัก หัวข้อ Open Questions)
- แนะนำ cache ผลลัพธ์ล่าสุดไว้ใน memory (ไม่ใช่ persistent storage) โดย **key คือชุดแบรนด์ + รัศมี + พิกัด** เพื่อให้สลับไปมาระหว่างหน้า Map ⇄ List Store โดยไม่ต้องยิง query ซ้ำถ้าเงื่อนไขไม่เปลี่ยน
- Query ที่ union หลายแบรนด์เข้าด้วยกันยังนับเป็น 1 request ต่อ Overpass server ไม่ได้แปลว่ายิ่งติ๊กแบรนด์เยอะยิ่งยิง request เยอะขึ้นเป็นเส้นตรง — แต่ query string ยาวขึ้นและ server ต้องประมวลผลมากขึ้น ควรเฝ้าดู timeout ถ้าติ๊กครบทุกแบรนด์พร้อมกัน
