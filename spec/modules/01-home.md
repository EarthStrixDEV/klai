# Module: Home (Landing)

## หน้าที่
หน้าแรกของแอป ทำหน้าที่เป็น landing page — อธิบายว่าแอปทำอะไร สร้างความน่าเชื่อถือ แล้วพา user ไปสู่การใช้งานจริง (Map / List Store)

## เป็นหน้า Static — ไม่มีการดึงข้อมูลสด
หน้านี้ไม่ต้องเรียก Overpass API หรือขอ GPS อัตโนมัติตอนโหลดหน้า เนื้อหาทั้งหมดคงที่ ยกเว้นปุ่ม CTA ที่ trigger action

## การทำงานทีละส่วน

**Nav bar** — โลโก้ + ลิงก์ไปหน้าอื่น (หน้าหลัก / แผนที่ / รายชื่อร้าน / เกี่ยวกับ) + ปุ่ม CTA "หาร้านใกล้ฉัน" มุมขวา

**Hero**
- ปุ่ม **"ค้นหาร้านใกล้ฉัน"** (primary) → เมื่อกด: ขอ permission ตำแหน่ง GPS จาก browser (`navigator.geolocation.getCurrentPosition`) → ถ้า user อนุญาต ส่งพิกัดไปที่โมดูล Map พร้อมค้นหาทันที → ถ้า user ปฏิเสธ แสดงข้อความแจ้งเตือนว่าต้องเปิด permission ตำแหน่งถึงจะใช้ฟีเจอร์นี้ได้ พร้อมลิงก์สำรองไปหน้า List Store แบบพิมพ์ค้นหาเอง
- ปุ่ม **"ดูแผนที่ทั้งหมด"** (secondary) → พาไปหน้า Map โดยตรง โดยยังไม่ขอ GPS (browse mode เฉยๆ ให้ user เลื่อนดูแผนที่เอง)

**Trust bar / How it works / Features** — เนื้อหาอธิบายล้วนๆ ไม่มี logic — Features section ควรมีหัวข้อพูดถึง "เลือกได้หลายแบรนด์พร้อมกัน" (7-Eleven, Café Amazon, อินทนิล, พันธุ์ไทย, Black Canyon, Chao Doi ฯลฯ) เป็นจุดขายหลักตั้งแต่ v0.5 — ไม่ใช่แอปหา 7-Eleven อย่างเดียวอีกต่อไป

**CTA banner** (ท้ายหน้า) — ปุ่ม "เริ่มค้นหาเลย" ทำงานเหมือนปุ่ม hero หลัก (ขอ GPS → ไป Map)

**Footer** — ลิงก์ไปหน้าอื่น + ข้อความ disclaimer สั้นๆ (ฉบับเต็มอยู่ในหน้า About)

## Dependency
- ต้องมี Map module พร้อมรับพารามิเตอร์ตำแหน่งเริ่มต้น (lat/lng) ที่ส่งมาจากหน้านี้ เพื่อไม่ต้องขอ GPS ซ้ำสองรอบ
- ปุ่ม CTA จากหน้านี้ (ทั้งปุ่ม hero และ CTA banner) ส่งไปหน้า Map โดยใช้ **ชุดแบรนด์เริ่มต้น = ติ๊ก 7-Eleven ไว้อย่างเดียว** (ค่า default ของ Brand Registry) — user ไปปรับเพิ่ม/ลดแบรนด์เองที่หน้า Map/List Store ภายหลังได้
