# Module: About

## หน้าที่
หน้าเนื้อหา static อธิบายที่มาของแอป แหล่งข้อมูล และช่องทางแจ้งปัญหา — ไม่มี dynamic data หรือ API call ใดๆ ทั้งหมดเป็นเนื้อหาคงที่

## เนื้อหาหลัก

1. **แอปนี้คืออะไร** — อธิบายสั้นๆ ว่าเป็นโปรเจกต์ส่วนตัว ไม่มีค่าใช้จ่าย ไม่มี backend/database ของตัวเอง
2. **แหล่งข้อมูล** — อธิบายว่าข้อมูลร้านค้ามาจาก OpenStreetMap (ชุมชนผู้ใช้ทั่วโลกช่วยกัน map ไว้) ดึงแบบ real-time ทุกครั้งที่ค้นหา ไม่ได้เก็บสำเนาไว้เอง
3. **Disclaimer (สำคัญ — ต้องเด่นชัด)**

## ช่องทางแจ้งปัญหา

### แจ้งปัญหาทั่วไป (บั๊ก/ข้อเสนอแนะ)
ลิงก์ `mailto:` เปิดโปรแกรมอีเมลของ user พร้อม subject ตั้งไว้ล่วงหน้า (เช่น "แจ้งปัญหา Klai") — ยังไม่ต้องมี backend/form ใดๆ

### แจ้งพิกัดร้านผิด/ตกหล่น (แนะนำเพิ่มใหม่)
แทนที่จะสร้างระบบแจ้งพิกัดผิดเอง (ซึ่งต้องมี DB เก็บ — ขัดกับสถาปัตยกรรม) **ให้ deep-link ตรงไปที่หน้าแก้ไขของ OpenStreetMap เอง**:
- ปุ่ม/ลิงก์ "แก้ไขข้อมูลร้านนี้บน OpenStreetMap" → เปิด `https://www.openstreetmap.org/edit#map={zoom}/{lat}/{lon}` (หรือลิงก์ node ตรงๆ ถ้ามี node id) ในแท็บใหม่
- User ที่อยากแก้ไขพิกัด/ชื่อร้าน/tag ต่างๆ จะไปแก้ที่ต้นทางข้อมูลจริง (OSM) ซึ่งจะสะท้อนกลับมาที่แอปนี้อัตโนมัติในการ query ครั้งถัดไป (อาจใช้เวลาสักพักกว่า OSM data จะ sync)
- ข้อดี: ไม่ต้องสร้าง/ดูแลระบบ report ของตัวเองเลย ตรงกับสถาปัตยกรรม "0 maintenance" ของโปรเจกต์ 100%
- ข้อเสีย: user ต้องสมัคร OSM account เองถึงจะแก้ไขได้จริง (เป็น friction เล็กน้อยที่ยอมรับได้)

## อัปเดตใน v0.8 — แหล่งข้อมูลราคาน้ำมัน
เพิ่มย่อหน้าแยกจากย่อหน้า "แหล่งข้อมูล" เดิม อธิบายว่าราคาน้ำมันที่โชว์ในหน้า Gas Station Combo Finder มาจาก**คนละแหล่ง**กับพิกัดร้าน — ดึงจากข้อมูลเปิดของสำนักงานนโยบายและแผนพลังงาน (EPPO) ผ่าน data.go.th (ผ่าน community wrapper [thai-oil-api](https://github.com/max180643/thai-oil-api)) ไม่ใช่ OpenStreetMap — ย้ำอีกครั้งว่าเป็น**ราคาอ้างอิงระดับแบรนด์ทั้งประเทศ ไม่ใช่ราคาจริงต่อสาขา**
